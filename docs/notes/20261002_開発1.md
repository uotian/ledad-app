## 1. 現在の構成

- **ローカルMacアプリ**：Tauri 2 + Next.js静的出力 + React + TypeScript。AI通信と保存は同梱NodeサービスへIPCで依頼する。実行時に開発サーバーやlocalhostの待受ポートは不要。macOS 14以降・Apple Silicon向け。
- **聞き取り**：Gemini Live Transcription（`gemini-3.5-transcribe-live`）。Macのマイクまたはシステム音声をSwiftでPCMへ変換し、短期トークンで送る。
- **候補生成**：OpenAI Responses API + Structured Outputs、`gpt-6-luna`（2026-10-05に切替、推論なし）。本人向け日本語・発話本文・根拠を分ける。
- **音声出力**：`gemini-3.8-flash-lite-tts`。選択と発話を分離し、中断位置を保持。停止・終了後に遅れて届いた音声は再生しない。
- **資料**：PDF、UTF-8のTXT・Markdown。発表資料／関連資料／スクリプトを区別。PowerPointはPDFへ変換して登録する。
- **保存**：`~/Library/Application Support/jp.ledad.desktop/`。APIキーはキーチェーン。音声は永続保存しない。ブラウザの開発検証だけは`.data/`を利用する。
- **構成**：画面は親子関係を追えるディレクトリと1コンポーネント1ファイル。共通処理は用途別の`lib`、画面と操作の接続は`hooks`、ローカル呼び出し口は8個の`service/handlers`に整理。

最初にWeb版を選んだ判断は誤りで、10:30にMacアプリへ修正した。以下の時系列にはその修正経緯も残す。

## 2. 現在の仕様

- 日本語で操作し、日本語・英語・中国語（簡体字）の発話を選択する。
- 資料の登録時は「本人のみ・背景参考可・発言根拠不可・共有不可」。本人が用途ごとの許可を選ぶ。非公開の内容からは固定された表現方針だけを発言生成へ渡す。
- 原稿はページごとに確認・編集する。外国語は明示的に翻訳し、実際に話す原稿を確認して開始する。
- 質問の検知だけでは発話しない。Presenterは質問検知から候補を作り、Audienceは本人の指示から質問候補を作る。
- 入力と会議相手への送音は別。Macのスピーカーで再生しただけでオンライン会議へ届くとは表示しない。会議サービスの音声共有または設定済み仮想音声機器を使う。
- 表示はライト・ダーク・Mac連動。AI処理ごとの会議ID・モデル・取得できた利用量を記録し、設定画面から確認・出力できる。

### 要件補足：非公開の背景資料

ユーザーから「非公開資料はAIが回答の参考にしてよいが、その情報を発表・回答には出したくない」と補足。例は、個人への本音やトラブルの裏事情。初案の単純な入力除外を変更する。前述の登録時の既定は「本人のみ・背景参考のみ・共有不可」に修正する。

- 「AIの参考にする」「発言に情報を使う」「画面共有する」を別の権限にする。
- 背景資料は別のAI処理で読み、固定された回答方針（個人批判を避ける、手順に焦点を当てる等）の選択だけを返す。自由文・人物名・事実をこの処理から発話生成へ渡さない。
- 実際の候補生成には発言許可のある資料、会議で聞いた内容、本人の指示、選択された回答方針だけを渡す。
- 「本人のみ」は発言根拠・共有を許可しない。機密ラベルを変えるだけで許可状態を上げない。
- AIに背景を読ませる以上、該当の資料はOpenAI APIへ送る。会議へ出さないことと、外部AIへ送らないことを画面で区別する。

### 基盤・実API接続・画面の実装

- セッション／資料／聞き取り／候補／私的指示／実発話を別の型として定義。会議ごとのJSONと資料を`.data/sessions/`へ保存する。
- APIの入力検証、ローカルホスト・同一オリジン制限、キーのサーバー限定読み込みを追加。
- 非公開背景資料の解釈と、会議で話す候補の生成を二段階にした。背景からは固定された表現方針の列挙値だけが後段へ届く。
- PDFの文字抽出とプレビュー、TXT・Markdown登録、ページごとの原稿編集・明示的翻訳を追加。
- Gemini音声出力の停止・再開・発表の中断保持を実装。選択した文章のコピーを発話処理へ渡し、再生成中にも勝手に差し替えない。
- 会議画面は「会話」「候補」「私的チャット」の3領域。Presenterはスライドと原稿を追加。共有画面はサーバー側で公開可能なスライドと実発話字幕だけを抽出する。
- 終了時に音声・生成を停止し、実際の会話と再生完了区間だけから議事録を作る。Markdown出力と削除を追加。
