# 機能とパッケージ構成の整理

2026年10月5日。既存の画面変更を引き継ぎ、10回に分けて参照関係・保存形式・実行経路・配布物を確認しました。使われていない実装を削除し、残した機能には理由を付けています。

## 10回の確認と変更

| 回 | 確認対象 | 対応と判断 |
| --- | --- | --- |
| 1 | 依存パッケージと使用箇所 | アプリ・スクリプト・テストから参照されない開発依存 `agent-browser` を削除。画面確認時だけ外部ツールとして使用。実行時依存13個は用途を確認して維持。 |
| 2 | 到達しない画面 | 既に設定画面から外れていた `UsageHistory`、専用CSS、処理名の表示マップを削除。概算料金が使う利用記録の保存とAPIは維持。ファイル保存は実際に使うMarkdownへ限定。 |
| 3 | 古い音声機器選択 | 入出力ID、未使用のデバイス一覧コマンド、Swiftの機器列挙・個別指定、不要な権限を削除。入力元のマイク／PC音声は維持。RustからSwiftへ渡す引数位置も合わせた。 |
| 4 | 候補生成と私的チャット | 現在使われない「指示を候補生成へ適用する」引数・状態・プロンプトを削除。相談は相談として独立。旧チャット記録は読み込めるが、私的な指示を候補生成へ送らない。 |
| 5 | 保存値とReactの状態 | 未使用の発表位置の保存値、表示されない速報時刻の受け渡し、外部から使わないsetterを削除。再生位置は音声クラスが保持し、発言開始時刻は記録用に維持。 |
| 6 | CSSと翻訳文 | 不使用の説明用CSS、参照のない翻訳75件を削除。動的クラスと複数行の翻訳は確認して保持。 |
| 7 | APIの共通処理 | 14ハンドラーのローカル要求検査・例外処理を既存の `route` に集約。会議・資料の読み出しが外部要求を拒否する回帰テストを追加。 |
| 8 | 開発起動 | `npm run dev` で画面とAPIをまとめて起動・停止し、両方の変更を自動反映。TauriとE2Eは画面だけの `dev:ui` を使用。設定ボタンに重なるNext.jsの開発インジケーターを非表示にした。 |
| 9 | 旧データと同梱構成 | 旧デバイスIDの読込・再保存を確認。同梱依存フォルダを毎回作り直し、更新・削除前のファイルを残さないようにした。残骸を模擬したファイルが消え、同梱サービスでPDFを読めることを確認。 |
| 10 | 整理後の全体確認 | TypeScriptの参照を再追跡し、画面・サービス入口から到達しないソースモジュールは0件。単体・画面テスト、開発起動、Macアプリ作成と署名検証を実施。古いテスト前提とREADMEも現行動作に合わせた。 |

## 残した構成

- **Next.js・React・react-dom**：静的画面と開発時の自動反映。
- **Tauri API・dialog・fs**：Macとの通信、保存先選択、Markdown保存。
- **OpenAI・Google GenAI SDK**：会話生成・翻訳・認識・音声生成。
- **pdfjs-dist・canvas**：PDFの読込に必要な実装。Macアプリへ必要なネイティブモジュールも同梱。
- **zod・lucide-react・react-markdown**：保存／入力の検証、画面アイコン、チャットの文章表示。

会話の速報と録音による見直し、失敗時の速報保持、非公開資料の利用境界、保存待ち、発話・聞き取りの別々の停止は必要な処理として残しました。これらをまとめると、停止や再開の動作が変わるためです。

## 確認結果

- `npm ci`：成功。lockfileから依存を再導入。
- ESLint・TypeScript（未使用ローカル／引数の検査を含む）：成功。
- Vitest：29ファイル・139件成功。
- Playwright：全21件について成功を確認。全体実行で18件成功後、表示設定の古い寸法期待値と開発インジケーターの重なりを修正し、失敗した3件の再実行がすべて成功。
- 実API：Audienceの相談・候補・発話・議事録、PresenterのPDF共有・発話停止・回答・発表復帰・終了、会話の英中翻訳と保存を確認。
- 開発起動：画面とAPIの同時起動、APIのファイル変更による再起動、設定画面、ブラウザエラーなし、SIGINTで両方の待受ポートが閉じることを確認。
- 同梱サービス：会議作成と2ページのPDF抽出に成功。旧パッケージを模擬した残骸の除去も確認。
- `npm run app:build`：成功。Swift・静的画面・Rust・同梱サービスを生成し、アドホック署名検証後に `build/ledad.app` を更新。

音声の画面テストは生成WAVをChromiumでデコード・再生する確認です。物理マイク・スピーカー・PC音声の再取得、macOSの権限復旧は今回の確認には含めていません。

`npm audit` は開発用ESLint依存経路のhigh 5件を報告しています。提案された強制修正はNext用ESLint設定を14系へ下げるため適用していません。実行時依存の削減とは分け、現在のNext.jsと整合する更新を待つ項目です。

## 開発画面を確認する

```sh
npm run dev
```

`http://127.0.0.1:3000` を開きます。画面確認のたびに完成アプリをビルドする必要はありません。Mac固有の音声・権限を確認するときは `npm run app:dev`、完成アプリを更新するときは `npm run app:build` を使います。
