# 05.35 @You：言及の検知と整理

[AI Overview](00-overview.md) / [You](../02-frontend/03-meeting/02.02.02-you.md)

## 責務とAPI

Topics・Chat/Ask候補とは独立した`POST /api/sessions/:id/mentions`で処理します。

1. OpenAI `POST /v1/decisions`、固定モデル`gpt-6-luna`で本人への言及の可能性を判定します。処理名は`mention_detection`。
2. 検知した発言と前後2行をOpenAI Responsesへ渡し、`kind / summary / evidenceId / quote`を構造化出力します。モデルは`OPENAI_MODEL`、処理名は`meeting_mentions`、思考はnone、storeはfalseです。

名前・呼ばれ方は既存の手動設定を使い、AIにあだ名を生成させません。現行Profileには役割欄はありません。会話全体を文脈に、登録された本人への質問・依頼・その他の言及を拾います。同音の相づちや明らかな別人は除外します。旧方式の「同名の別人も抽出する」仕様からの変更です。後続会話による回答済み・対応完了の管理は対象外です。

## Fix優先と未Fix Liveの持ち越し

- 現在の会話全体を時刻順にDecisionsへ渡します。Topicsの引き継ぎ要約・資料・私的Chatは渡しません。
- `conversationForAnalyze`を共用し、統合Fixの本文を使います。`liveSegments`の訂正前原文を二重に送信しません。手入力・再生終了済みの自分の発話も確定扱いです。入力中の速報は含めず、Liveの確定イベントで追加された発言から扱います。
- 発言IDごとに本文と`settled`のSHA-256を保存します。初回・本文訂正・Live→Fixは判定対象です。本文が同一でもFix化したら再判定します。
- 未FixのLiveは確認済みになっても、次の更新の対象に含めます。配列へコピーし続けるキューではなく、現在の会話と確認済みリビジョンから対象を導出します。同じIDの最新版だけを扱います。
- Fix済みで未変更の発言は全文文脈には含めますが、再判定の質問には含めません。
- LiveがFixに統合されたら消えたIDの候補を除去し、統合先を再判定します。結果が空なら旧候補を取り消します。

## 判定・生成の検証

要求内だけ発言IDを`c1`等へ短縮し、対象行ごとのpredicateを一つのDecisions要求にまとめます。確率0.5以上を内容生成へ渡します。これは初期の暫定閾値で、日本語の正解付き実会話による校正は未実施です。

欠落・重複・未知の回答ID、拒否、範囲外や非数の確率は失敗とします。「言及なし」へ変換しません。内容生成では候補IDのみを根拠に許可し、引用が対象行の完全一致部分文字列であることを検証します。前後の行は内容理解のために渡し、別行から新しい候補は作りません。

どちらかが失敗・取消された場合、確認済みリビジョンと候補は更新しません。判定だけ成功した結果も消費せず再試行します。

## 実行・保存・表示

- 名前があり、会議がactiveなら実行します。最初は即時、その後は会話分析と同じ設定間隔を使いますが、実行中・失敗状態は独立します。
- 会話が変化したときに実行します。同一入力の未Fix Liveだけを理由に無限再送しません。新しい発言・訂正・Fix化が来れば、持ち越したLiveも再判定します。
- 失敗時は即時一回だけ再試行し、その後は入力の変更を待ちます。
- 設定変更、会議終了、画面の破棄時は進行中の要求を取り消します。
- 処理中に変更・削除・Fix化された発言は、応答時に送信時の本文・確定状態と突き合わせ、古い候補と確認済み印を採用しません。追加だけなら既存の有効な処理結果は保存します。次の更新で最新状態を処理します。
- `Session.mentionAnalysis`へ候補、確認済みリビジョン、更新時刻、言語、Profileキー、入力キーをまとめて保存します。Topicsの更新はこのフィールドを触りません。
- 旧`Analyze.mentions`は独立処理の初回成功まで表示用に読み継ぎます。新方式の処理済み情報には流用せず、全発言を確認します。
- Youの件数・更新時刻・処理中・エラーは独立処理を参照します。既存の引用ベースの表示重複排除は維持します。

## 料金と制約

Decisionsは入力のみ課金されるため、`mention_detection`では通常Lunaのキャッシュ割引や出力単価を使いません。入力単価・長文倍率は会議の料金スナップショットを使います。内容生成は通常のResponses料金です。両要求の利用記録・API詳細・失敗・取消を個別に記録します。

全文を送るため長時間会議では費用・入力サイズが増加します。黙って切り詰めず、上限超過はエラーとして扱います。前後2行では遠い参照先を十分に説明できない場合があります。実APIの利用資格・遅延・日本語精度は未検証です。
