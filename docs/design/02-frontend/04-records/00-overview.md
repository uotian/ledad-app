# 02.04 会議の記録

[Frontend](../00-overview.md)

会議の要約と原記録を表示し、Markdownへ書き出します。

- ヘッダー：会議名・ホームへの移動・Markdown保存
- 件数：発言数・完了した発話数・要約中の未回答と要確認の数
- 要約：要点・決定事項・次のアクション・質問と回答・注意事項
- 原記録：聞き取りと、再生完了が確認された発話

## 要約と画面遷移

- 会議終了後は自動で要約を作成します。失敗時や既存の未要約会議では作成ボタンから再試行できます。
- 編集内容の保存を待って生成を依頼し、結果を会議へ保存します。
- 生成に失敗しても原記録を保持し、再試行できます。
- 終了した会議は要約の成否にかかわらず再開できません。作成済みの要約は再作成しません。
- 会議画面と同じURLを使います。「会議へ戻る」は画面だけを切り替え、音声を自動再開しません。
- Markdownの保存に失敗した場合はエラーを表示します。
