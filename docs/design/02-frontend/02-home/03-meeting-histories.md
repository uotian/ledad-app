# 02.02.03 会議履歴

[ホーム](00-overview.md)

保存済みの会議を一覧で表示し、開く・削除する操作を受け付けます。

## 表示

- 準備中を除く会議の一覧とその件数を表示します。
- 履歴がない場合は見出しと「no data」を表示し、件数と一覧の枠線は表示しません。
- 要約がある会議にはチェック印を表示します。
- 作成時刻が新しい順に並べます。
- 最初の発言日時と、最初から最後の発言までの経過時間を表示します。

## アクション

### 全て削除

- 確認後、準備中を含む全会議と資料を削除します。

### 会議を削除

- 確認後、選択した会議と資料を削除します。

### 会議を開く

- 選択した会議を開きます。
