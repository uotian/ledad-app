# 02.02.02 会議設定

[ホーム](00-overview.md)

会議の設定と資料を準備し、会議を開始します。基本設定・詳細設定の入力値は、会議開始時と会議画面で使用します。

- 設定は会議ごとに保存し、開いたときに復元します。新しい会議は翻訳先も含めて保存済みの設定を引き継ぎます。翻訳先が未設定の場合は、その時点のアプリの表示言語を初期値にします。
- 未保存なら初期値を使い、音声入力は「PC音声＋マイク」です。

## 基本設定

会議名・言語・音声入力を設定します。

| 項目         | 選択肢・入力例                    |
| ------------ | --------------------------------- |
| タイトル     | 最大120文字。空欄は「新しい会議」 |
| 会議の言語   | 日本語 / 英語 / 中国語（簡体字） / フランス語  |
| 翻訳先の言語 | 日本語 / 英語 / 中国語（簡体字） / フランス語  |
| 音声入力     | PC音声＋マイク / PC音声 / マイク  |

会議の言語は認識と発言案に使います。アプリの表示言語とは別に指定し、翻訳先は準備画面で指定し、会議中は固定します。アプリの表示言語を変更しても、翻訳先や保存済みの翻訳は変わりません。Live・Fixedのプロバイダーは[アプリ設定](../01-layout/01.01-setting.md)で管理します。

## 詳細設定

聞き取りの条件を設定します。折り畳み可能で、初期表示では折りたたみます。

| 項目                   | 選択肢                               |
| ---------------------- | ------------------------------------ |
| 聞き取りの自動停止時間 | 10分 / 30分 / 60分 / 90分            |
| Fixed文字起こしの間隔  | 15秒 / 30秒 / 60秒 / 120秒           |
| 発話区切りの無音時間   | 50ms / 100ms / 200ms / 300ms / 500ms |

## 資料の追加

会議で使うファイルをアップロードし、登録済みの資料を一覧で表示します。折り畳み可能で、初期表示では折りたたみます。

- ファイル選択・ドラッグ＆ドロップ・画像の貼り付けで追加します。
- 一覧にはファイル名・サイズ・削除ボタンを表示します。

## 会議をはじめる

「会議を始める」ボタンで、未生成なら全原本から会議共通の参照文・用語集を生成し、成功後に聞き取りを開始して会議画面を開きます。失敗時は準備画面に留まります。開始前の明示的な生成も可能です。上限・再試行は[資料の読み取り](../../05-ai/10-document.md)を参照してください。
