# 02.01 レイアウト

[Frontend](../00-overview.md) / [サイドバー](01-sidebar.md) / [アプリ設定](01.01-setting.md)

全画面でサイドバーとメイン領域を共有します。

- 左側にサイドバー、右側にメイン領域を配置します。
- サイドバーにホームへの移動と設定を配置します。
- メイン領域にホーム・会議・記録画面を表示します。
- 会議の文字起こしカードとAIサポートカードは角丸16pxに揃え、間隔は横並び・縦並びとも12pxです。カード領域だけ左に8px・右に20pxの追加余白を取り、サイドバー右端・画面右端との間隔をそれぞれ32pxに揃えます。

## 配色

設定でライト／ダーク／システムを切り替えます。初期値はライトで、選択をlocalStorageの`ledad.theme`に保存します。「システム」はOSの外観に連動し、起動中の変更にも追従します。手動指定のライト／ダークはOSに連動しません。

ライトはアイコンに合わせたカフェモカの配色です。ダークは濃い茶色の背景とカード、明るいミルク色の本文、モカ色の差し色を使います。以下はライトの配色です。

- 背景はモカ（`#C79A70`）、カードはミルク色（`#F3E5D5`）です。
- カードとフォームの通常時の枠線は低彩度のグレーブラウンとし、ライトは`#C5BBB1`、ダークは`#453C35`でコントラストを控えめにします。共通カード・会議履歴・候補カード・入力欄に適用し、選択・フォーカス時も枠線色は変えません。
- モーダルの外枠もカードと同じ枠線色に揃えます。
- 選択中の背景（`--accent-soft`）はライトでカードのミルク色に近い薄茶色`#EAD8C5`、ダークで背面に近い黒茶色`#1E1713`とし、背景になじませながら選択を区別します。
- サイドバーはこげ茶（`#4B3022`）で、枠線を付けません。文字とアイコンは明るいミルク色です。
- 会議のフッターバーは背景と同じカフェモカ色とし、ボーダーと角丸を付けず、余白で区切ります。下端から8px空け、左右は12pxの余白を維持し、カード領域より左は8px・右は20px外側に配置します。デスクトップでは上のパネルと8pxの間隔を取ります。内側の余白は上下8px・左右20pxとし、右端の操作ボタンを分析カードの右端に揃えます。高さは内容に合わせます。文字と状態色はカフェモカの背景で読める濃さにします。
- 操作・選択はこげ茶系の背景色で示し、選択時の枠線・タブ下線・フォーカスリングによる強調は使いません。入力欄のフォーカスは背景色、キーボード操作のフォーカスは背景色・明度・文字の下線で区別します。本文は濃い茶色で表示します。
- 文字起こしの種別・音声状態・警告の意味色は保持し、各背景で読める濃さにします。
- ネイティブのタイトルバー背景は選択中のサイドバー色に揃え、ネイティブ外観は手動指定ではダーク、システム指定では固定を解除してOSに従います。フォームは選択中の外観に従います。共通の配色は`src/styles/theme.css`で管理します。

## ウィンドウサイズと位置

前回のサイズと位置を保存し、起動時に現在の画面内へ収めます。

- 最小サイズは幅980px・高さ700pxです。
- 初回起動時は、画面の利用可能な幅と高さに合わせてウィンドウを表示します。
- 2回目以降は保存済みのサイズと位置を復元します。
- モニターの変更などで画面からはみ出す場合は、サイズを縮めて位置を補正します。

画面の利用可能範囲はmacOSが定める領域とし、Dockの表示設定も反映します。
