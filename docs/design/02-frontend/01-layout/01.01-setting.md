# 02.01.01.01 アプリ設定

[レイアウト](00-overview.md)

アプリ全体に適用する表示・音声・AI接続を設定します。

- 一般設定とAPI設定をタブで切り替えます。
- サイドバーからは一般設定、ホームの接続状態からはAPI設定を開きます。

## 一般設定

名前・表示・音声・会話分析の設定を行います。

文字サイズは設定画面の一般・API設定にも即時反映します。閉じるボタンのフォーカスは枠ではなく背景色で示します。

| 設定               | 選択肢・入力例                           | 保存場所     |
| ------------------ | ---------------------------------------- | ------------ |
| 名前・呼ばれ方     | 自由入力（例：山田太郎、山田さん、Taro） | localStorage |
| 表示言語           | 日本語 / English / 中文（简体） / Français          | localStorage |
| 文字サイズ         | S / M / L                                | localStorage |
| 読み上げ音声       | Kore / Aoede / Puck / Charon             | localStorage |
| 会話分析後の待機時間 | すぐに送信 / 3秒 / 15秒 / 30秒 / 1分 | localStorage（旧3分・5分は1分として読み込み） |

名前・呼ばれ方は会話分析の`names`に渡します。現行実装ではカンマ・読点・改行で分割し、空白を正規化した氏名全体と空白区切りの各部分を重複除去します。

## API設定

APIキーの登録と、文字起こしに使うモデルの選択を行います。

| 設定                    | 選択肢・入力例                      | 保存場所     |
| ----------------------- | ----------------------------------- | ------------ |
| OpenAIのAPIキー         | 発行されたキーを入力（例：`sk-…`）  | Mac Keychain |
| GeminiのAPIキー         | 発行されたキーを入力（例：`AIza…`） | Mac Keychain |
| Live文字起こしのモデル  | Gemini / Apple SpeechTranscriber    | `state.json` |
| Fixed文字起こしのモデル | OpenAI / Gemini                     | `state.json` |

Live・Fixedの設定はBackendでも参照するため、Backendが読み書きする`state.json`に保存します。保存形式は[Data](../../06-data/03-persistence.md#アプリ設定)に定義します。
