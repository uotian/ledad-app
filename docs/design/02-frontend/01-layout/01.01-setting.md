# 02.01.01.01 アプリ設定

[レイアウト](00-overview.md)

アプリ全体に適用する表示・音声・AI接続を設定します。

- 一般設定とAI設定をタブで切り替えます。
- サイドバーからは一般設定、ホームの接続状態からはAI設定を開きます。

## 一般設定

名前・表示・会話分析の設定を行います。

文字サイズは設定画面の一般・AI設定にも即時反映します。閉じるボタンのフォーカスは枠ではなく背景色で示します。

| 設定               | 選択肢・入力例                           | 保存場所     |
| ------------------ | ---------------------------------------- | ------------ |
| 名前・呼ばれ方     | 自由入力（例：山田太郎、山田さん、Taro） | localStorage |
| 表示言語           | 日本語 / English / 中文（简体） / Français          | localStorage |
| 文字サイズ         | S / M / L                                | localStorage |
| 会話分析後の待機時間 | すぐに送信 / 3秒 / 15秒 / 30秒 / 1分 | localStorage（旧3分・5分は1分として読み込み） |

名前・呼ばれ方は会話分析の`names`に渡します。現行実装ではカンマ・読点・改行で分割し、空白を正規化した氏名全体と空白区切りの各部分を重複除去します。

## AI設定（v0.8.0）

「使用するモデル」は項目より大きな太字の見出しとし、右上にある「Geminiも使う」のチェックボックスで切り替えます。オフは「OpenAIのみ」、オンは「Geminiも使う」です。新規環境はオフで、「利用するAI」のセレクトは表示しません。

| 設定 | OpenAIのみ | Geminiも使う |
| --- | --- | --- |
| 聞き取り（Live） | OpenAI（既定） / Apple | OpenAI / Apple / Gemini（既定） |
| 聞き取り（Fixed） | OpenAI | OpenAI（既定） / Gemini |
| 音声出力 | OpenAI | OpenAI / Gemini（既定） |
| 声の種類 | Marin（既定） / Cedar | 選択中の音声出力の声 |

Geminiの声はKore（既定） / Aoede / Puck / Charonです。文章処理・相談のモデルはモードによらずOpenAIです。自動フォールバックは行いません。

- OpenAIキーは常時、Geminiキーは併用時だけ表示します。モードを切り替えても登録済みキーは削除しません。
- OpenAIしか選べないFixed・音声出力は、セレクトではなくモデル名を表示します。
- AppleはMacのみ選択可能です。「OpenAIのみ」は外部AIの利用先を示し、端末内認識のAppleを含めます。
- モードごとにLive・Fixed・音声出力の選択を保持します。初めて併用に切り替えたときは上表の既定値、戻したときは前回の選択を使います。
- 声は音声出力に連動して絞り込み、プロバイダーごとの前回の声を復元します。
- 保存中は関連する選択を無効化し、保存失敗時は変更前の値を維持してエラーを表示します。
- Liveは次の聞き取り開始時、Fixedは次の再認識要求時、音声出力・声は次の発言再生時に反映します。発言再生開始時に利用モードと声を取得し、その発言の途中や再開では変えません。

Live・FixedとモードはBackendの`state.json`、音声出力と声はlocalStorageで管理します。旧設定の移行と保存形式は[アプリ設定](../../06-data/03-persistence.md#アプリ設定)を参照してください。

タブ名は「AI」とし、重複するAPIキー見出しと保存先の説明文は表示しません。声の種類は使用するモデル欄の音声出力の次に置きます。読み上げの詳細は[TTS](../../05-ai/33-tts.md)を参照してください。

### カスタム接続先

AIタブの先頭に「接続先URL（base_url）」と「接続先を保存」を表示します。空欄で保存すると公式接続に戻ります。入力中は現在の接続先を維持し、保存成功後に制限を反映します。指定中は「Geminiも使う」をオフ・操作不可、LiveをApple固定として表示します。Fixed・音声出力・声はOpenAIのみです。

保存契約・復元・音声使用中の制約・接続先に必要なAPI互換性は[AI接続先](../../05-ai/02-connection.md)を参照してください。

接続先URLの入力欄はプレースホルダー「空欄：OpenAI公式」で未指定時の接続先を示し、常設の補足説明文は表示しません。
