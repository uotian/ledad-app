# 02.01.01 サイドバー

[レイアウト](00-overview.md)

サイドバーにホームへの移動と設定を配置します。

左・上下の余白と角丸はなく、画面端に接して配置します。幅は66pxです。カードとフッターの位置は維持し、サイドバー右端からフッターまでは24px、フッターから画面右端までは12px空けます。会議カードだけは左に8px・右に20pxの追加余白を取り、サイドバー右端・画面右端との間隔をそれぞれ32pxに揃えます。

ホームと設定のアイコンは24px、線幅は1で揃えます。配色は[レイアウト](00-overview.md#配色)を参照してください。

## ホームへの移動

上部の家型アイコンのホームボタンからホーム画面へ戻ります。

- 移動前に音声を停止し、編集内容を保存します。
- 保存に失敗した場合は現在の画面に残ります。

移動時の条件は[画面遷移](../05-navigation.md)にまとめます。

## 設定ボタン・ダイアログ

下部の設定ボタンから設定ダイアログを開きます。

- 現在の画面にダイアログを重ねて表示します。
- 一般設定タブを初期表示します。

設定項目と保存範囲は[アプリ設定](01.01-setting.md)にまとめます。
