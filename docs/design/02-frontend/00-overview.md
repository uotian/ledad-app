# 02 Frontend

[Design Overview](../00-overview.md)

ホーム・会議・記録画面をレイアウトで構成し、会議の状態やユーザー操作に応じて表示を切り替えます。

アプリ全体で次の表示仕様を共有します。

- 配色はカフェモカをベースに、こげ茶を差し色とします。詳細は[レイアウト](01-layout/00-overview.md#配色)を参照してください。
- 表示言語は日本語・英語・簡体字に対応します。
- 表示言語と文字サイズの設定は全画面へ適用します。
