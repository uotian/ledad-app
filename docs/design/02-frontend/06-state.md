# 02.06 状態管理

[Frontend](00-overview.md)

画面だけで使う一時状態と、次回も使う保存データを分けて管理します。

- **編集中の会議**：Frontendで編集を即時反映し、Backendへ順番に保存します。
- **画面・タブ・ダイアログ**：表示中の画面で保持し、再読み込み時に初期化します。
- **音声・AI処理**：接続状態、音量、途中の認識・翻訳、取消状態を実行中だけ保持します。
- **音声データ**：録音バッファ、接続、再生位置を実行中だけ保持します。
- **アプリ設定**：プロフィール、表示言語、文字サイズなどをlocalStorageへ保存します。
- **保存済み会議**：Backendがローカルファイルとして管理します。

## 非同期処理

- 保存を直列化し、応答待ち中の編集も保持します。再試行を含む手順は[保存と更新](../06-data/03-persistence.md)にまとめます。
- 翻訳・再認識は会議ID、発言ID・原文、言語、状態を照合し、発言順を保って反映します。古い応答で訂正済みの内容を上書きしません。
- Fixedへの置き換えに失敗した場合はLiveを残します。元LiveのID・時刻は[データの関連](../06-data/02-relations.md)に従って保持します。
- 途中表示は一時的に保持し、確定した発言を保存します。
- 会話分析は保存を待たず最新の会話を送り、入力の重複を抑制します。
