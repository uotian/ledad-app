# 02.03.01.02 API履歴

[ヘッダー](01-header.md)

## ヘッダー

タイトルは「API履歴」です。タイトルのすぐ右にOpenAI・Geminiの切り替えボタンを表示します。閉じるボタンは右端に置きます。

## 提供元の絞り込み

OpenAI・Geminiの2択で履歴と処理別の集計を切り替えます。各ボタンの提供元名の後ろに、その提供元の全処理の件数と概算料金を表示します。処理の絞り込みではこの集計を変更しません。提供元・処理ボタンは`OpenAI(80件/4.7円)`のように、名称・括弧・区切りの間にスペースを入れません。開くたびに初期値はOpenAIです。切り替えると処理の絞り込みを解除します。

## 処理絞り込みボタン

選択中の提供元の処理ごとの件数・概算料金を表示し、クリックで履歴を絞り込みます。

「全て」と各処理のボタンを並べます。

## 履歴テーブル

APIの利用履歴を表示します。詳細ボタンでAPIの入出力を確認できます。

「不利用」は、成功した応答を表示に使わなかったことを示します。未取得の使用量は「—」で表示します。

## 課金画面へのリンク

モーダル左下に、選択中の提供元の課金画面へのリンクを一つ表示します。履歴の表だけがスクロールし、リンクは表示を維持します。履歴がない場合や取得エラー時もリンクを表示します。
