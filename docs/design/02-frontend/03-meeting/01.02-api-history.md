# 02.03.01.02 API履歴

[ヘッダー](01-header.md)

## ヘッダー

タイトルは「API履歴」です。タイトルのすぐ右に、選択した提供元の課金画面へのリンクを表示します。「両方全て」のときは両方のリンクを表示します。閉じるボタンは右端に置きます。

## 提供元の絞り込み

「両方全て」「OpenAI全て」「Gemini全て」を件数・概算料金付きで表示します。初期値は「両方全て」です。切り替えると処理の絞り込みを解除します。

## 処理絞り込みボタン

選択中の提供元の処理ごとの件数・概算料金を表示し、クリックで履歴を絞り込みます。

「すべての処理」と各処理のボタンを並べます。

## 履歴テーブル

APIの利用履歴を表示します。詳細ボタンでAPIの入出力を確認できます。

「不利用」は、成功した応答を表示に使わなかったことを示します。未取得の使用量は「—」で表示します。
