# 02.03.02.01 Talk

[会議画面](00-overview.md)

聞き取った発言と翻訳を時系列に表示します。

## 表示

- 発言行はホバーで背景を変えません。

- Liveは速報、Fixedは録音の再認識結果です。
- 日時はLive・Fixedとも控えめな文字色（ライトは茶色、ダークは明るいカフェモカ色の`--muted`）と太字（600）で表示します。種別ラベルはLive（途中の発言を含む）を赤茶、Fixedを青で表示します。ライトは`#A43D38` / `#285FA6`、ダークは`#E88D86` / `#8AB4E8`を使います。本文・翻訳・手入力の記録は従来の文字色を使います。
- 原文を左に表示し、翻訳を後から右に反映します。
- 末尾を表示しているときは、新しい発言に合わせて自動スクロールします。上にスクロールしている間は、表示位置を動かしません。
