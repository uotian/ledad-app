# 02.03.02.03 Controller

[会議画面](00-overview.md)

聞き取りの状態と会議の操作を表示します。中央に「会議の言語 → 翻訳先の言語」（例：日本語 → 英語）を表示し、現在の設定に追従します。狭い画面では状態表示を上段へ折り返します。

## 状況の表示

### 1. Live聞き取りの進行状況

| 表示                | 状態                                 |
| ------------------- | ------------------------------------ |
| Live聞き取り準備中… | 音声入力の準備・接続中               |
| Live聞き取り中      | 音声を取得中。入力レベルを表示します |
| Live聞き取り停止中  | 停止処理中・停止後、または会議終了後 |

### 2. Fix聞き取りの進行状況

Fix間隔が30秒の場合、次の順に表示します。

| 表示                           | 状態                                                     |
| ------------------------------ | -------------------------------------------------------- |
| Fix聞き取り中（あと約○秒）     | 前回のFix処理完了後に表示。最大30秒(*)からカウントダウン |
| Fix区切り待ち        | Liveの発言の区切りを待機中                               |
| Fix聞き取り中（−○秒） | 区切り後の文脈音声の取得中は−1秒から−5秒まで表示      |
| Fix処理中            | 送信した音声を再認識中                                   |

(*) 会議に保存されたFixed文字起こしの間隔（設定画面では非表示）

区切り前の収集と区切り後の追加音声取得は、同じ「Fix聞き取り中」で表示します。区切り前の残り秒数に文脈取得の5秒は加算しません。区切り後は追加取得の最初の1秒間を−1秒、次を−2秒として−5秒まで表示します。境界通知が遅れて音声がすでに届いている場合は、その取得位置に対応した秒数から表示します。区切り待ちの長さは未確定のため、この秒数には含めません。録音・区切り判定・送信タイミングは変更しません。

Fixの進行表示は黄色、文字サイズは11pxです。

### 3. 会話分析の進行状況

| 表示                      | 状態                              |
| ------------------------- | --------------------------------- |
| 会話分析待ち（あと約○秒） | 更新対象があり、送信まで待機中    |
| 会話分析中                | Topics・You・入力候補の自動解析中 |

会話分析の進行表示はピンク、文字サイズはFixと同じ11pxです。待機中と解析中に表示します。更新対象がない場合は非表示にします。

## アクション

- 停止：聞き取りを止め、残った音声処理と保存を待ちます。
- 再開：停止中の会議の聞き取りを再開します。
- 終了：先に聞き取りを停止するとボタンを表示します。残った処理の完了後に実行でき、会議を保存して記録画面へ進み、要約を作成します。聞き取り中はボタンを表示せず、何かしらの処理中には実行できません。

会話分析の待機中は処理中に含めません。

ホームへの移動・アプリ終了では処理を停止して保存したのち移動・終了します。
