# 02.03.02.02.04 Ask

[AIサポート](02.02-ai-support.md)

会話分析で検出した入力候補もしくは手動入力文を使って会議相手への発言案を作成できます

## アクション

- 入力欄や入力候補から発言案の作成を依頼します。
- 発言案を保存し、発話文を編集できます。
- 発言案を読み上げます。

発話文は会議の言語で作成し、翻訳先の言語が異なる場合は区切り線を挟んで参考用の訳文を下に表示します。
発話文を編集した場合は、内容が一致しなくなる参考訳を非表示にします。

## 発話の履歴

読み上げを開始したカードは、完了・途中停止・失敗後も本文と確認訳をAskに残します。新しい候補の生成中・生成後・再読み込み後も表示します。発話記録のない古い候補は従来どおり置き換えます。

カードには「音声生成中」「読み上げ中」「発話済み」「途中停止」「読み上げ失敗」を表示します。発話開始後は本文を編集できません。現在一時停止中の発言は既存の再開操作を使い、完了後やアプリ再起動後はスピーカーアイコンで最初から新しい発話記録を作成します。再読み上げボタンは文字ラベルを表示せず、操作名はツールチップと読み上げ用ラベルで伝えます。終了した会議では読み上げできません。

保存済みの候補と`utterances`を参照し、カードの状態には最後の発話記録を使います。保存形式は変更しません。
