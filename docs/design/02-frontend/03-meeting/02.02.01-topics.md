# 02.03.02.02.01 Topics

[AIサポート](02.02-ai-support.md)

会話の概要を話題ごとに表示し、「何について、どんな話があり、どうなっているか」を読み取れるようにします。結論や決定のない話も対象です。生成方針は[会話分析のプロンプト](../../05-ai/30-analyze.md#topicsの差分更新)を参照してください。

Backendが[根拠発言の時刻で整列した結果](../../05-ai/30-analyze.md#出力)を、その順序のまま表示します。

## 表示

- トピックのタイトルと要点。人名・対象名と行動の対応を残し、具体的な出来事を一般論に置き換えません。詳細は[要約の記述方針](../../05-ai/30-analyze.md#topicsの補足文)を参照してください。
- タイトル右側に、最後にその話題が話された時刻からの経過時間（「3分前」など）を小さく薄い文字で表示します。`topicEvidence`から根拠発言の時刻を取得し、表示中は毎秒更新します。要約の生成完了時刻は使いません。時刻を取得できない場合は表示を省略し、ホバー時には日時を表示します。経過時間の更新だけではスクロールしません。
- `01`・`02`などの表示番号は現在の並び順で付け直します。同じ話題を識別する内部の`id`とは別です。
- 最後に話された順に並べ、最新の話題を末尾に表示します。以前の話題が再開したら、同じトピックを更新して末尾へ移します。要約の書き直しやFixによる訂正だけでは順序を変えません。
- 要点はMarkdownで表示し、複数なら一項目一要点の箇条書き、一つなら短文を基本にします。小見出し・入れ子・表も表示できます。表は横スクロールできます。HTML・画像・リンクは表示しません。リンクの文字列は残します。

内容は領域内でスクロールできます。
