# 02.03.02.02.02 You

[AIサポート](02.02-ai-support.md)

新規・訂正された発言から検出した、登録されたあなたの名前への言及・質問・依頼を蓄積して表示します。後の会話による回答済み・対応完了の管理は行いません。重複防止・Fix訂正・削除への追従は[言及の検知と整理](../../05-ai/35-mentions.md)を参照してください。

## 表示

- 言及の件数
- 種別・要点・引用
- 発言時刻

名前が未登録の場合は設定を案内します。内容は一覧内でスクロールできます。

@YouはTopics等と同じAnalyze応答で検知・整理します。登録名と会話の文脈から本人への言及を判断し、明らかな別人や同音語は除外します。Fixを優先し、未Fix Liveは次の更新へ持ち越します。
