# 02.03.02.02 AIサポート

[会議画面](00-overview.md)

会議のAIサポートを4つのタブで表示します。

タブ列は外側とタブ間に余白を設けず、選択したタブの背景をカードの上端・左右端まで広げます。両端はカードの角丸に沿って切り抜き、選択時の枠線・下線は付けません。タブ列と本文の区切り線はカードの外枠と同じ色にします。

- [Topics](02.02.01-topics.md)：トピック
- [You](02.02.02-you.md)：登録されたあなたの名前への言及・質問・依頼
- [Chat](02.02.03-chat.md)：AIへの私的な相談
- [Ask](02.02.04-ask.md)：会議相手への質問・発言案

## 会話分析との関係

Topics・You・Chat・Askは共通の[会話分析](../../05-ai/30-analyze.md)の結果を使います。Youの抽出規則は[言及の検知と整理](../../05-ai/35-mentions.md)を参照してください。Topicsにはトピック、Youには登録されたあなたの名前への言及・質問・依頼、Chat・Askには、それぞれの入力候補を表示します。

Topics・Youを表示しているときは、パネル最下部に右寄せで「最終更新 32秒前」のような経過時間を、本文より小さい10px（文字サイズ設定に追従）で表示します。表示中の分析結果の`updatedAt`（成功時の完了時刻）から毎秒更新し、1分以上は分・時間・日の単位で表示します。時刻は通常表示せず、ホバー時だけ日時を表示します。分析中・失敗時には前回の成功時刻を保持します。未生成時、Youの登録名が分析時と一致しない場合、Chat・Askでは表示しません。

Topics・Youは、分析結果の更新成功時とタブを開いたときに一覧の最下部へスクロールします。経過時間のカウント更新や分析中・失敗時にはスクロール位置を変えません。

Youの更新時刻・処理中・失敗はAnalyzeと共通、件数は表示する言及から求めます。旧`mentionAnalysis`は統合Analyzeの初回成功まで読み継ぎます。
