# 03 Backend

[Design Overview](../00-overview.md)

会議の操作を受け付け、入力の検証、状態の更新、AIやデータへのアクセスを行います。

- リクエストの検証と処理結果・エラーの返却
- 会議の開始・終了、発言案・相談・発話・要約の記録
- AIの呼び出し（Fixed文字起こし・翻訳・要約・発言案・チャットなど）
- Gemini Live接続用の一時トークン発行
- 会議・資料・利用記録の読み書き

## 処理の分担

- 操作の入出力と検証条件は[01 操作と入出力](01-operations.md)に定義します。
- AIへ渡す情報と生成条件は[AI](../05-ai/00-overview.md)にまとめます。
- 生成・翻訳の結果を呼び出し元へ返し、会議の更新処理で保存します。
- 設定・文字起こし・翻訳・会話分析は会議全体の更新でも保存します。更新順序と再試行は[Data](../06-data/03-persistence.md)にまとめます。
